Modified June 12

# expenseKubex

## Project Summary

expenseKubex is an AI-assisted expense tracking application built to gain hands-on experience with the complete Software Development Life Cycle (SDLC).

The application will allow users to upload receipts, extract information using OCR and AI, and manage expenses through a web application.

This project is educational and not intended for production use.

---

## Objectives

- Build a complete full-stack application
- Learn frontend and backend architecture
- Implement OCR and AI workflows
- Deploy to cloud infrastructure
- Practice modern development workflows

---

## Scope

Included:

- Authentication
- Receipt upload
- OCR extraction
- Expense management
- User management
- Deployment

Excluded:

- Payroll
- Mobile support
- Accounting integrations
- Advanced reporting

---

## Stakeholders

Primary:
- Project Developer

Secondary:
- Employers
- Technical reviewers

---

## Constraints

- Limited development time
- Educational focus
- Low-cost technologies
- MVP-first development

---

## Success Criteria

The project succeeds if:

- Users can upload receipts
- OCR extracts data
- Expenses persist
- Deployment succeeds
- Architecture can be explained

---

## Deliverables

- Working application
- Documentation
- AWS deployment
- Demonstration
