# expenseDensify

AI-assisted expense tracking system built to learn the complete Software Development Life Cycle (SDLC).

The application allows users to upload receipts, extract expense information using OCR and AI, create expense reports, and process approval workflows through a web application.

---

# Project Goals

This project exists to gain practical experience with:

- Full-stack development
- REST APIs
- PostgreSQL
- Authentication & authorization
- OCR and AI integration
- Docker
- CI/CD
- AWS deployment
- Modern software architecture

---
